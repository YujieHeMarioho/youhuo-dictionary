# 有活词典

原生 macOS 词典和学习工作台，参考网易有道翻译 11.3.20 的页面布局与常用操作，使用独立代码、图标和公开许可的词库。应用不要求登录。

## 已实现

- 770,611 条离线英汉词条：音标、中文及英文释义、词形变化、前缀建议、中文反查。
- 本机语音朗读；查词和翻译历史。
- 主动查剪贴板（⌘L）、macOS 服务中选中文字查词；可选辅助功能授权后的划词自动释义浮窗。
- 显式开始/停止录音及音频文件导入转写，使用 Apple 支持的设备端语音识别；需要系统权限及受支持的语言模型。
- 单词本、分组、笔记、筛选、复习卡片。
- 双栏文本翻译，使用 Apple Translation；首次使用需要系统下载语言包，语言支持以系统为准。
- TXT、Markdown、PDF 文字提取与阅读；图片及交互截图的本机 OCR，可将文字送到翻译页。
- 本机知识文档库、JSON 备份与恢复、深色模式。
- 可选有道智云文本翻译 API，应用 ID 与密钥只存于 macOS 钥匙串。

## 范围

这是可运行的常用功能重建，不代表与有道全部服务等价，也尚未建立“80–90%”的定量覆盖结论。原应用的登录、账号同步、订阅、专有词典及例句、实时翻译同传（录音转文字已实现）、AI 问答/润色、完整 Office 文档排版翻译尚未实现。AI 与同传页会说明当前不可用，不会生成假答案。图片/PDF 功能提取文字，不保留文档版式。鼠标悬停取词尚未实现；划词浮窗需手动授予辅助功能权限，默认关闭，不读取剪贴板或联网。

离线查词、收藏、朗读、OCR 不需要购买服务。Apple 本机翻译需要安装语言包。可选有道 API 需使用自己的开发者凭据，其额度及收费由有道决定；本项目不会自动购买或调用收费服务。查看[官方 API 文档](https://ai.youdao.com/DOCSIRMA/html/transapi/trans/api/wbfy/index.html)。

## 运行与构建

需要 macOS 15+ 与包含 macOS 15 SDK 的 Xcode。构建脚本仅为当前进程选择 Xcode，不修改系统设置。

```sh
bash build.sh
node tools/test_frontend.js
```

打开 `build/有活词典.app`。本地构建使用 ad hoc 签名。词库压缩包随仓库提供，构建时解压。

## 数据与许可

学习数据在 `~/Library/Application Support/Youhuo Dictionary/state.json`，与仓库分离；修改时保存前一版本。备份包含学习内容和导入文本，不含 API 凭据。默认本机功能不上传文本；主动选择有道 API 时，待翻译文字发送至有道官方服务。

词库来自 [ECDICT](https://github.com/skywind3000/ECDICT)，固定版本与校验摘要见 `data/ECDICT-SOURCE.json`；MIT 许可证见 `data/ECDICT-LICENSE.txt`。未包含原应用的二进制、资源、账号或用户单词本。
